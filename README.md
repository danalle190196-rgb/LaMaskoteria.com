# La Maskoteria · Tienda de Mascotas en Venezuela

Sitio web oficial y catálogo online para **La Maskoteria**.

## Características
- **Catálogo interactivo:** Navegación por categorías (Alimentos, Accesorios, Juguetes, Higiene, Camas) con filtros por chips.
- **Carrito de compras:** Agrega productos, modifica cantidades y calcula el total en USD automáticamente.
- **Checkout directo a WhatsApp:** Formulario con datos de contacto, tipo de entrega (a domicilio o retiro en tienda) y métodos de pago venezolanos (Pago móvil, Transferencia, Zelle, Efectivo USD).
- **Tasa BCV oficial en tiempo real:** Consulta automática cada 30 minutos a la API oficial (DolarAPI) con respaldo en almacenamiento local.

## Ejecución Local
Puedes correr el servidor local incluido en PowerShell:
```powershell
.\server.ps1
```
Abre automáticamente `http://localhost:8080/`.
